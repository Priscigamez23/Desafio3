# 📚 AppAprende

## Descripción
AppAprende es una aplicación móvil educativa desarrollada en Android Studio con Kotlin. Su objetivo es facilitar el acceso a recursos de aprendizaje, permitiendo a estudiantes y docentes consultar, compartir y organizar materiales educativos.

## Objetivo
Ofrecer una plataforma donde los estudiantes puedan encontrar recursos educativos y los docentes puedan administrar materiales de apoyo para el aprendizaje.

## Funcionalidades principales

### 👨‍🎓 Estudiante
- Registro e inicio de sesión.
- Visualización de libros, videos y artículos.
- Búsqueda de recursos por título e identificación.
- Consulta de descripciones y enlaces.
- Guardar y quitar recursos de favoritos.
- Calificar recursos.
- Consultar sus recursos favoritos.

### 👩‍🏫 Docente
- Registro e inicio de sesión.
- Agregar nuevos recursos educativos.
- Editar recursos existentes.
- Eliminar recursos.
- Administrar libros, videos y artículos.

## Tecnologías utilizadas
- Kotlin
- Android Studio
- XML para el diseño de interfaces.
- API REST para la comunicación y gestión de datos.
- Git y GitHub para el control de versiones.

## Categorías de recursos
- 📚 Libros
- 🎥 Videos
- 📰 Artículos

## Estructura general
- `app/`: contiene el código fuente de la aplicación.
- `app/src/main/java/`: contiene las clases Kotlin.
- `app/src/main/res/layout/`: contiene los diseños XML.
- `app/src/main/res/drawable/`: contiene los recursos gráficos.
- `app/src/main/AndroidManifest.xml`: configuración principal de Android.
